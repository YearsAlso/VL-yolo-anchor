模块采用 Tauri v1 双端架构：
- 前端 `src/` 是 Vite + React 18 + TypeScript SPA，入口 `main.tsx` 挂载 `<App>`，`App.tsx` 用 Ant Design Tabs 组织四个业务页面（TaskPlanPage / AnnotationReviewPage / InspectionReportPage / TrainingExportPage），共享组件 `OBBCanvas.tsx` 与自定义 hook `useCanvasViewport.ts` 负责 OBB 标注画布。
- 数据层集中在 `services/api.ts`，通过 Axios 实例直连 FastAPI 后端 `http://127.0.0.1:8765`；类型定义统一在 `types/index.ts`，前后端契约由这些接口维护。
- 原生壳在 `src-tauri/`，`Cargo.toml` 仅依赖 `tauri 1`、`serde`、`serde_json`，`main.rs` 使用 `Builder::default().run(generate_context!())` 极简启动，无自定义 Rust command。
- `tauri.conf.json` 将开发模式 devPath 指向 `http://localhost:5173`，构建产物目录为 `../dist`，并通过 allowlist 白名单放行对 `http://127.0.0.1:8765/*` 的 HTTP 请求；CSP 关闭以允许本地资源加载。
- 依赖方向单向：pages → services/types → 外部 FastAPI；Tauri 原生侧不反向调用前端。
