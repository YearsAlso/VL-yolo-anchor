- 所有后端交互封装在 `services/api.ts` 中，页面组件只调用命名函数（如 `runPlan`、`getReport`、`imageUrl`），不直接使用 axios。
- 前后端数据结构以 `types/index.ts` 中的 TypeScript interface 声明，并在 api.ts 中通过泛型 Promise<T> 返回，保证类型安全。
- 任务相关 API URL 使用模板字符串拼接 `/api/tasks/${encodeURIComponent(task)}/...`，并对路径参数做 encodeURIComponent 编码。
- 图片 URL 通过 `imageUrl()` 工具函数统一处理相对路径补全为 `http://127.0.0.1:8765` 绝对地址，避免硬编码重复。
