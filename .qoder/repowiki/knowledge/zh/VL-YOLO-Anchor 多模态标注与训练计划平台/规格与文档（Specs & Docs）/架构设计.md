本模块为纯文档仓库，无可执行代码，由两个子目录构成：`specs/` 存放每个能力的 `*.spec.md` 正式规格文件，统一采用“功能描述 / 输入约束 / 输出约束 / 边界条件 / 验收标准”五要素结构（见 `platform-core.spec.md`、`test-suite.spec.md`），并通过 `specs/README.md` 规定其为唯一可信源；`docs/sdd-workflow.md` 定义 Spec-First → Design → Implement → Verify → Archive 的变更流水线，配合 `/opsx:*` 命令在 `changes/<id>/` 中产出 proposal/design/delta spec/tasks，最终归档合并入 `specs/`。依赖方向单向：实现层（`src/`、`tests/`、`gui/`）严格遵循本模块中的 spec 约定，本模块不反向依赖任何源码。
