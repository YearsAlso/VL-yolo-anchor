模块由两个并列子目录构成：`config/` 存放 YAML 格式的运行时配置，其中 `global.yaml` 定义模型（Qwen2.5-VL）、推理阈值、路径、服务器与日志等全局选项；`task_template.yaml` 作为新建任务时的默认模板，包含类别映射、训练超参、数据集划分、质检规则与评估指标。`prompts/` 存放三个独立 Agent 的提示词文件（`plan_agent.yaml`、`annotate_agent.yaml`、`inspect_agent.yaml`），每个文件统一采用 `system_prompt` + `user_prompt_template` 两段式结构，并通过 `{}` 占位符注入任务上下文（如 class_mapping、annotation_rules、w×h 尺寸等）。`prompts/prompt_versions/README.md` 约定了提示词版本归档策略：活跃提示词位于根级，重大变更时以 `<agent>_v<n>.yaml` 快照形式保留历史版本，确保实验可追溯。依赖方向单向：上层代码读取这些 YAML 并渲染为 LLM 输入，本模块不依赖任何 Python 包。
