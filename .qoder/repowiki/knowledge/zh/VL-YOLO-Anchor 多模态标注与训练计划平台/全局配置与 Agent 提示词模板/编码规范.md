- 所有配置与提示词均使用 YAML 格式，并通过缩进层级组织 model/inference/paths/server/logging 等逻辑分组。
- 提示词文件统一采用 `system_prompt` 描述角色与输出约束、`user_prompt_template` 提供带 `{}` 占位符的用户输入模板的结构。
- Agent 输出被强制约束为严格 JSON/YAML 结构（空数组、质量分数、结构化计划模块），禁止自然语言解释。
- 提示词中的动态参数通过 `{class_mapping}`、`{w}`、`{h}`、`{task_description}` 等花括号占位符注入，而非字符串拼接。
- 提示词版本管理遵循 README 约定：活跃版本置于 `prompts/*.yaml`，重大变更时在 `prompt_versions/` 中以 `<agent>_v<n>.yaml` 归档。
