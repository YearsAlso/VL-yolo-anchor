模块以 `src/api_server.py` 为 HTTP 入口（FastAPI），通过全局单例 `TaskManager` 和 `Pipeline` 协调任务生命周期与步骤编排。
- `core/`：`task_manager.TaskManager` 负责 `<tasks_root>/<name>/` 目录结构（images、ai_labels、candidate_labels、dataset、task.yaml）的 CRUD；`pipeline.Pipeline` 定义固定步骤 `_STEPS = (plan, annotate, inspect, split)`，每个步骤调用对应 Agent 并持久化配置或产物。
- `agents/`：`BaseAgent` 抽象类提供 prompt YAML 加载与日志，`PlanAgent`/`AnnotateAgent`/`InspectAgent` 实现具体步骤；LLM 后端通过 `LLMClient` Protocol 注入，默认使用 `StubLLMClient` 离线返回确定性 JSON 计划，便于无模型环境端到端运行。
- `utils/`：纯函数工具包，`file_utils` 提供图片枚举与目录创建，`yaml_utils` 统一 YAML 读写，`image_utils`/`obb_utils` 处理图像与 OBB 几何。
依赖方向单向：api_server → core → agents → utils，agents 不反向依赖 core，保证步骤可独立替换。
