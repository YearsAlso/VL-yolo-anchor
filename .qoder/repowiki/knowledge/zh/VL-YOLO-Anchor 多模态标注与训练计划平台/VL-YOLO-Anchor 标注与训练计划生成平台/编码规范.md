- 所有公开模块顶部使用 `from __future__ import annotations` 启用 PEP 563 延迟求值，统一类型注解风格。
- Agent 通过继承 `BaseAgent` 并实现 `run` 方法接入 Pipeline，LLM 后端以 `LLMClient` Protocol 注入而非硬编码。
- Pipeline 对 LLM 输出采用 JSON→YAML→stub fallback 的三层解析策略，确保异常输出不会中断流水线。
- HTTP 层使用 Pydantic `BaseModel` 声明请求/响应体，并通过 `@app.get/post` 装饰器集中注册路由，错误统一转为 `HTTPException`。
- 文件与目录操作统一委托给 `utils.file_utils.ensure_dir` 与 `list_images`，避免在各处重复实现路径创建与扩展名过滤。
- YAML 读写统一走 `utils.yaml_utils.load_yaml/save_yaml`，空文件返回空 dict 且非 mapping 抛出 `ValueError`，保证配置一致性。
