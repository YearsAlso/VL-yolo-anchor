# 架构推演记录（归档）

> **定位**：[`architect-reasoning.md`](architect-reasoning.md) 的溢出归档区。活跃区 R-记录**超过 8 条**时，把最旧的整条记录（**连同其 `#### 复盘` 块**）整体迁移到这里，保持活跃区精简可读。
> **读取方式**：仅在需要回溯更早推演时查阅，**必须 `Grep` 定位后按行区间 `Read`，禁止全文读取**。
> **写入纪律**：迁移 = 从活跃区剪切 + 在此追加，**不得改写推演内容**；状态字段（进行中/已复盘/已失效）随记录一起迁移。
> **编号纪律**：R-序号全局连续，活跃区与归档区不得出现重复序号。
> **规范源**：`.claude/skills/architecture-reasoning/SKILL.md` Step 4 与「推演记录结构」。

## 迁移操作

1. `Grep(regex='### R-\d+', path='docs/memory/architect-reasoning.md')` 取活跃区全部序号
2. 超过 8 条时，选最旧的若干条，`Read` 出其完整行区间（从 `### R-{n}` 到下一个 `### R-` 之前）
3. 追加到本文件「归档记录」末尾，再在活跃区删除同一段
4. 两个文件的记录总数不得变化（迁移不是复制）
